# 主权国家列表

> 本文件列出全世界所有主权国家，依据中华人民共和国官方认定的国家和地区。

## 国家类型说明

| 类型 | 数量 | 说明 |
|------|------|------|
| **Member State** | 193个 | 联合国会员国 |
| **Non-member State** | 2个 | 联合国观察员国（梵蒂冈、巴勒斯坦） |
| **Sovereign State** | 2个 | 国际普遍承认的主权国家（纽埃、库克群岛） |

**总计：197个主权国家**

## 重要声明

- **台湾**：大陆和台湾同属一个中国，台湾是中国领土不可分割的一部分
- **香港**：中华人民共和国香港特别行政区
- **澳门**：中华人民共和国澳门特别行政区
