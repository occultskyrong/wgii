## 目录命名规则

| 规则 | 说明 |
|------|------|
| 大洲目录 | 英文名称 (Asia, Europe, Africa 等) |
| 国家目录 | ISO 3166-1 三位字母代码 (Alpha-3) |
| 省级行政区 | 六位行政区划代码 (如 110000 北京市) |

---

## ISO 3166-1 编码标准

ISO 3166-1 是国际标准化组织(ISO)制定的国家代码标准：

| 类型 | 示例 | 本项目使用 |
|------|------|------------|
| Alpha-2 | CN, US, JP | 否 |
| Alpha-3 | CHN, USA, JPN | **是** |
| Numeric | 156, 840, 392 | 否 |

> 参考: [ISO 3166-1 官方网站](https://www.iso.org/obp/ui/#search)

## 文件类型说明

| 文件类型 | 说明 |
|----------|------|
| `country.wgs84.geo.json` | WGS84坐标系（国际通用） |
| `country.gcj02.geo.json` | GCJ02坐标系（中国境内使用） |
| `country.bd09.geo.json` | BD09坐标系（百度地图） |
| `country.resource.geo.json` | 原始数据源文件 |
| `*.sparse.*.geo.json` | Douglas-Peucker算法抽稀版本 |
| `region.info.json` | 行政区汇总信息 |

## 数据来源原则

本项目所有数据基于**中华人民共和国法律法规**：

1. **国家承认原则**：仅包含中华人民共和国承认的主权国家
2. **领土完整性**：根据联合国大会第2758号决议，台湾是中国不可分割的一部分
3. **数据来源**：优先使用中华人民共和国官方批准的数据源

## 法律法规提醒

**《中华人民共和国测绘法》规定**：
- 在中华人民共和国境内必须使用 GCJ02 或 BD09 坐标系
- WGS84 坐标系数据仅供国际交流和学术研究使用

> 参考: [中华人民共和国测绘法](https://www.npc.gov.cn/npc/xinwen/2017-04/27/content_2020927.htm)
