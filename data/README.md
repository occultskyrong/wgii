## 目录概述

| 目录 | 类型 | 说明 |
|------|------|------|
| `data/` | **数据源** | 原始地理数据存储，包含各国边界数据 |

## data 目录结构

数据源目录，包含所有国家/地区的GeoJSON边界数据。

### 目录命名规则

所有国家/地区数据文件夹使用 **ISO 3166-1 三位字母代码** (Alpha-3) 命名。

示例：
- `CHN` - 中国 (China)
- `USA` - 美国 (United States)
- `ROU` - 罗马尼亚 (Romania)
- `SRB` - 塞尔维亚 (Serbia)

### ISO 3166-1 编码标准

ISO 3166-1 是国际标准化组织(ISO)制定的国家代码标准，包含：
- **Alpha-2**: 二位字母代码（如 CN, US, JP）
- **Alpha-3**: 三位字母代码（如 CHN, USA, JPN）- **本项目使用此编码**
- **Numeric**: 数字代码（如 156, 840, 392）

> 参考标准：[ISO 3166-1 官方网站](https://www.iso.org/obp/ui/#search)

### data 目录详细结构

```
data/
├── CHN/                             # 中国
│   ├── country.wgs84.geo.json       # 国家边界 - WGS84坐标系
│   ├── country.gcj02.geo.json       # 国家边界 - GCJ02坐标系(火星坐标)
│   ├── country.bd09.geo.json        # 国家边界 - BD09坐标系(百度)
│   ├── country.*.sparse.*.geo.json  # 抽稀版本 (1/2/5/10/20米)
│   └── region/                      # 省级行政区边界
│       ├── 110000.wgs84.geo.json    # 北京市 - WGS84
│       ├── 110000.gcj02.geo.json    # 北京市 - GCJ02
│       ├── 110000.bd09.geo.json     # 北京市 - BD09
│       ├── 110000.*.sparse.*.geo.json # 北京市 - 抽稀版本
│       ├── region.info.json         # 省级汇总信息
│       └── ...                      # 其他省份 (共34个)
│
├── USA/                             # 美国
│   ├── country.wgs84.geo.json
│   └── country.resource.geo.json
│
├── geo/                             # 其他地理数据
│   └── china_admin_divisions.json   # 中国行政区划汇总
│
├── ROU/                             # 罗马尼亚 (ISO: ROU)
├── SRB/                             # 塞尔维亚 (ISO: SRB)
└── ...                              # 其他国家 (共196个)
```

### 文件类型说明

| 文件类型 | 说明 |
|----------|------|
| `country.wgs84.geo.json` | WGS84坐标系数据（国际通用） |
| `country.gcj02.geo.json` | GCJ02坐标系数据（中国境内使用） |
| `country.bd09.geo.json` | BD09坐标系数据（百度地图） |
| `country.resource.geo.json` | 原始数据源文件 |
| `*.sparse.*.geo.json` | Douglas-Peucker算法抽稀版本 |
| `region.info.json` | 行政区汇总信息 |

## 数据来源原则

本项目所有数据基于**中华人民共和国法律法规**和官方认定：

1. **国家承认原则**：仅包含中华人民共和国承认的主权国家和地区
2. **领土完整性**：台湾、香港、澳门为中国领土不可分割部分
3. **数据来源**：优先使用中华人民共和国官方批准或认可的数据源

### 中国相关数据处理

根据联合国大会第2758号决议，中华人民共和国是包括台湾在内的全中国的唯一合法代表：

| 地区 | 行政区划代码 | 处理方式 |
|------|-------------|----------|
| 台湾省 | 710000 | 中国省份，数据存于 `data/CHN/region/` |
| 香港特别行政区 | 810000 | 中国特别行政区，数据存于 `data/CHN/region/` |
| 澳门特别行政区 | 820000 | 中国特别行政区，数据存于 `data/CHN/region/` |

## 法律法规提醒

**《中华人民共和国测绘法》规定**：
- 在中华人民共和国境内必须使用 GCJ02 或 BD09 坐标系
- WGS84 坐标系数据仅供国际交流和学术研究使用
- 使用地图数据请务必遵守国家法律法规

> 参考：[中华人民共和国测绘法](https://www.npc.gov.cn/npc/xinwen/2017-04/27/content_2020927.htm)
